# Проверка Veyra MVP

Исходная проверка MVP: 30 сентября 2026. Обновление возрастного диапазона и демоданных: 1 октября 2026. Локальная Windows-среда, Node.js 22, PostgreSQL 16, production-сборка Next.js 16.3.6, Chrome через Playwright.

## Результат Definition of Done

Успешно выполнен реальный сценарий:

1. В браузере зарегистрирована новая компания и заполнен onboarding.
2. Создано исследование с аудиторией 18–30, вопросами Single choice / Text, наградой 135 баллов.
3. Исследование опубликовано и появилось у нового подходящего респондента.
4. Респондент зарегистрировался, ответил и получил ровно 135 баллов.
5. Ответ появился у компании; count=1, completion rate=100%, распределение ответов пересчитано.
6. Запущен настоящий OpenAI-анализ по одному специально созданному синтетическому ответу.
7. Показаны executive summary, инсайты, темы, цитаты, рекомендации и ограничения.
8. Каждый возвращённый источник цитаты совпал с существующим ответом.
9. Повторный запрос анализа вернул тот же ID записи кеша.
10. AI Assistant ответил на вопрос по этому исследованию.
11. Тестовые аккаунты и их исследования удалены через API.

AI-тест не отправляет данные других компаний, email, nickname или секреты: контекст ограничен новым тестовым research. Факт успешного вызова не означает гарантии качества всех будущих AI-выводов; для production нужны evals и проверка интерпретаций человеком.

## Что не проверено / ограничения

- Результаты дополнительной проверки Docker приведены ниже.
- Не проводились нагрузочное тестирование, независимый security audit и тесты в Safari/Firefox.
- Регистрация доступна с 12 до 99 лет включительно. Проверка возраста и родительского согласия, реальные выплаты и speech-to-text не реализованы.
- Нет email verification, password reset и MFA; они необходимы перед публичным production-запуском.
- Нет автоматического сохранения незавершённых ответов после перезагрузки.
- Полный перечень ограничений и следующие шаги — в README.

Локальное приложение доступно на http://localhost:3000, проверенное контейнерное приложение — на http://localhost:3002. Данные сохраняются в PostgreSQL; команды повторного запуска и demo accounts находятся в README.
