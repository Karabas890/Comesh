## Развёртывание

Caddy обслуживает отдельный HTTPS-listener :8444 с корнем /srv/veyra-info.
compose.production.yaml монтирует только landing/dist в этот каталог, read-only.
Для обновления контента достаточно заменить файлы в /opt/veyra/landing/dist.
Основное Next.js-приложение пересобирать не требуется.
Конфигурация TLS и автоматическое продление сертификата находятся в deploy/Caddyfile.standalone.

Пример локального просмотра из корня репозитория:
python -m http.server 4178 --bind 127.0.0.1 --directory landing/dist
